# Responsible use

This project automates parts of a job search. The person using it is responsible for everything submitted in their name.

## Rules this project follows, and you should too

- **Be truthful.** Every claim in a resume, form answer, or cover letter must be true. The resume verifier exists to stop invented skills, titles, dates, and metrics. Do not weaken it.
- **Keep a human in the loop.** Run in review mode, read what was filled, and approve applications yourself. Switch to automatic submission only after many clean runs, and keep the daily cap low.
- **Respect site rules.** Many employers and job boards restrict automated access or automated applications. Read the terms of any site you use. This project applies only on a company's own career site or its applicant system, and never through aggregators.
- **No circumvention.** The agent stops at CAPTCHAs, "verify you are human" checks, phone or SMS codes, and assessments. Do not add code that bypasses them.
- **No outreach on your behalf.** It does not message recruiters or send connection requests.
- **Protect other people's data.** Do not commit resumes, logs, or mailbox contents. Do not put employer-confidential product, device, or project names in applications. The banned-terms list helps with that.
- **Legal and immigration questions are yours.** Answers about work authorization, visa sponsorship, export-control status, or compliance declarations must reflect your real situation. The templates contain examples only. Nothing in this repository is legal or immigration advice. Ask your school's international student office or a qualified attorney if you are unsure.

## Things to be honest about

- Automated applications can be rejected or flagged. Volume is not a strategy, and a few well-matched applications usually beat hundreds of weak ones.
- An application counts as submitted only when you see the employer's on-screen confirmation text, not when a log says so.
- The model can make mistakes in free-text answers. Read them.
